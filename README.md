# Chat App

A real-time chat application built with modern web technologies, enabling seamless communication between users.

## Features

- **Real-time Messaging** – Instant text communication using WebSockets.
- **User Authentication** – Secure login and registration system.
- **Group Chats** – Create and manage group conversations.
- **Typing Indicators** – See when someone is typing.
- **Message Read Receipts** – Know when messages are read.
- **Responsive UI** – Works on both mobile and desktop.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript (React/Vue/Other framework if used)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB/MySQL/Firebase (whichever applies)
- **Real-time Communication:** Socket.io/WebSockets
- **Authentication:** JWT, OAuth, Firebase Auth

```sh
# Clone the repository

cd chatApp

# Install dependencies
npm install

# Set up environment variables (e.g., .env file)
PORT=5000
DB_URI=mongodb://localhost:27017/chatapp
